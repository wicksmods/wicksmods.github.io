The addons
Wick's Bags
Bags and bank in one window, sorted into categories you control. Quiver and reagents collapse to a single counted tile.
/wbags
CurseForge GitHub
Wick's Comforts
Square minimap in Wick chrome, richer tooltips, auto loot, auto repair and junk selling. Every one of them off until you turn it on, bar the fix for an error the game itself throws.
/wcomfort
CurseForge GitHub
Wick's Gear
What to chase while leveling, a browser for what drops where, and a paperdoll to try pieces on: right-click anything to see what it would do to your stats, green up and red down. Ships item ids and nothing else, so every number comes from your own client.
/wgear
CurseForge GitHub
Wick's Trade Hall
What a run earned and what trade chat is offering, in one window. The session side values loot at vendor price and marks what it cannot price rather than guessing; the board keeps one line per person per subject, sorted into selling, buying, enchanting, crafting and travel. It reads the channel and never posts.
/wth
CurseForge GitHub
New
Wick's Reminders
Timers, alarms and event reminders that keep counting between sessions, with Snooze and Done on every alert. TBC Classic Anniversary and Forever.
/remind
CurseForge GitHub
Wick's Survivors
Wave survival minigame. Biomes, bosses, weapons and passives, inside your UI. Runs on Forever and on TBC.
/survivors
CurseForgeGitHub
